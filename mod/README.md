# Halcyon Visuals — Fabric-мод

Клиентский мод с визуальными дополнениями Halcyon для **Minecraft 1.21.1** (Fabric Loader 0.16+, Fabric API, Java 21).
Только внешний вид: ничего не автоматизирует и не даёт игровых преимуществ.

## Управление

- **Правый Shift** — меню визуалов (9 вкладок).
- **H** — перезагрузить конфиг из файла.
- **F6** — скриншот без интерфейса.

## Сборка и проверка

```
./gradlew build       # build/libs/halcyon-visuals-0.8.0.jar
./gradlew runClient   # игра с модом (или test-mod.bat)
```

## Конфиг

`config/halcyon/hud.json` — формат совместим с экспортом конструктора HUD на сайте.

## Структура

- `src/main/java/dev/halcyon/visuals/hud` — HUD, уведомления, прицел, скриншот-режим
- `.../gui` — меню, редактор расположения, стеклянные окна, фон меню
- `.../effects` — эффекты боя, аура, обводка, небо, лут
- `.../skins` — скины мечей, удочек, плащи
- `.../perf` — буст FPS
- `.../mixin` — точки встраивания в игру
- `tools/` — генераторы текстур
